# Create Objects – Удобная система управления категориями и объектами
Простой инструмент для организации информационных карточек с режимами доступа.


## Описание
Create Objects — это веб-платформа для создания, редактирования и совместного использования категоризованного контента с поддержкой регистрации, авторизации и ролевого доступа. Проект реализован на **Flask** с использованием **Docker** для обеспечения масштабируемости и простоты развертывания. Главная цель — обеспечить удобную организацию информации.

### Основные функции:
✅ **Управление пользователями**:
- Регистрация и вход пользователей с поддержкой кодового слова (admin-code) для дополнительной безопасности.
  Администраторы могут назначать/изменять кодовое слово через панель управления.
- Личные кабинеты пользователей с отображением созданного ими контента и фильтрами.

✅ **Работа с категориями и объектами**:
- **Обычные пользователи** могут создавать свои категории и карточки, редактировать только свой контент.
- **Администраторы** имеют права на редактирование *любого* контента, перемещение объектов между категориями и назначение кодовых слов.
- Возможность скрывать объекты от гостей для всех пользователей.

✅ **Интерактивность**:
- Комментарии под контентом (доступны всем авторизованным пользователям).
- Удобная **карта сайта** (категория → подкатегория → объект).
- Поиск по всему сайту на главной странице.

✅ **Админ-панель**:
- Управление контентом с фильтрами для быстрого поиска.
- Инструменты для администратора: редактирование, удаление, перемещение объектов, настройка кодовых слов.

## Техническая реализация

### Stack
- **Backend**: Flask (Python 3.12+)
- **База данных**: PostgreSQL (через `psycopg2`)
- **Контейнеризация**: Docker + Docker Compose
- **Тестирование**: `pytest` + `coverage`
- **Линтинг**: Ruff
- **Версионирование**: `uv`

### Запуск проекта
Требуется установка [Docker] и [Make].
